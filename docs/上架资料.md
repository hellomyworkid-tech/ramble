## 描述（≤4000）

**中文**

想到什么，说一句就记下。

「明天下午三点交房租 3200」——随口记把它整理成一条待办和一个账单提醒，付款时一键记成支出。中午吃饭花了 35、护照明年三月到期、装修师傅还欠我两千……怎么说都行，AI 帮你归好类，你确认后再保存。

【一句话，自动整理】
• 待办：说了时间就按时提醒，支持子任务、重复和优先级
• 账本：自动识别金额和分类，支持多个账户、多种货币和预算
• 账单和到期：信用卡、房租、订阅、证件、保险、合同，到期前提醒你
• 应收应付：别人欠你的、你欠别人的先记着，收到或付出时一键记账
• 笔记：长期跟踪的事和要留着的资料，AI 帮你理顺语句、标出重点

【问一问】
「这个月吃饭花了多少」「下周有哪些账单」「上次体检甘油三酯多少」，直接问就行。账目数字都在手机上计算。

【AI 读文件】
拍小票自动填金额。体检报告、合同、保修卡，AI 总结要点记进笔记，并建议复查、续期提醒。

## App 隐私（营养标签）

选「否，我们不从此 App 中收集数据」（Data Not Collected）。理由，审核问到时可以这样回答：

- 开发者没有服务器，App 里没有统计、广告、崩溃上报等第三方 SDK。
- iCloud 同步用的是用户自己的 iCloud 私有数据库，开发者读不到。
- 云端 AI 是用户自己填的 API Key，文字由 App 直接发给用户自己选的服务商，开发者拿不到，也不是开发者的合作方。
- 汇率接口和 Hugging Face 的请求里没有用户数据。

如果想更保守，也可以申报「用户内容 › 其他用户内容」，用途选「App 功能」、不关联身份、不用于追踪。两种说法都和隐私政策一致；按 Apple 对「收集」的定义（开发者或其合作方能在超出实时处理所需的时间内访问），推荐第一种。

## 给审核员的备注（App Review Information › Notes，用英文）

```
Ramble has no account or sign-in, and every feature works without an API key.

How to try it:
1. Tap the bar at the bottom ("Say something, AI tidies it"), then the keyboard icon, and type for example:
   "pay rent 3200 tomorrow at 3pm, lunch was 35". Tap "Tidy" to see the AI result, then Save.
   The paperclip next to the microphone adds a photo or file (a receipt, a contract) for the AI to read.
   AI tidying runs on device: Apple Intelligence if it's enabled, or the open-source Qwen3 model
   that can be downloaded in Settings › AI Tidying (about 2.3 GB, Wi-Fi only).
2. If neither on-device model is available on the review device, every item can also be added by hand
   with the + buttons on each tab.

The app is free with no in-app purchases. Its source code is public (MIT License):
https://github.com/hellomyworkid-tech/Ramble

Optional features:
- "Cloud AI" lets users enter their own API key for Anthropic, OpenAI, Google or any OpenAI-compatible
  endpoint. Text is sent from the device directly to that provider; we operate no servers. It is off
  unless the user sets it up, and the app asks for consent before the first request to each provider.
- Open-source models (Qwen3 by Alibaba, Apache 2.0) are downloaded from huggingface.co as model weights.
  They are data, not executable code, and run with Apple's MLX framework.
- iCloud Sync uses the user's private CloudKit database.

The microphone and speech recognition are used only while the user dictates; the camera only for
receipts and documents.
```

审核联系人填你自己的姓名、电话、邮箱（只给审核员看，不公开）。不需要演示账号，「需要登录」不勾选。

## App Store Connect 里另外要注意的两个开关

- 「定价与销售范围 › Apple 芯片 Mac 上的 iPhone 和 iPad App」：**取消勾选**。语音模型、相机和后台下载没有在 Mac 上测过。
